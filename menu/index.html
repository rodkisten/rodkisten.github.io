Persistência sem aprisionar seu estado.

Você pode armazenar o snapshot inteiro ou transformar os dados antes e depois do storage.

RodMenu.aio.settings({
  id: "aio-settings",
  store: {
    persist: {
      key: "aio:settings:v1",
      storage: "local",
      debounceMs: 120,
      persistOn: ["change", "submit"],
      transform: {
        toStorage(values) {
          return {
            telegram: values.telegram,
            download: values.download,
            quality: values.quality
          };
        },
        fromStorage(stored) {
          return stored;
        }
      }
    }
  },
  fields: [/* ... */]
});
