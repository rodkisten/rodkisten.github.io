RodMenu
v1.0.0 · IIFE · Shadow DOM
Declarative UI surface engine

Um schema.
Qualquer menu.

Bottom sheets, modais, drawers, action sheets e formulários completos, sem framework. O mesmo schema muda de forma sem virar um ninho de componentes.

Uma engine, muitas superfícies.

RodMenu mantém schema, estado, validação e actions independentes da apresentação. No iPhone ele pode ser um bottom sheet; no desktop, um modal. Troque uma string, não uma arquitetura.

01

Shadow DOM por padrão

CSS isolado da página hospedeira e tokens próprios, ideal para userscripts, ferramentas e páginas de terceiros.

02

Mobile-first de verdade

Safe areas, Visual Viewport, swipe-to-dismiss, scroll lock, focus restore e bottom sheet como comportamento padrão.

03

Schema completo

Inputs textuais, select, multi-select, radio, checkbox groups, switch, range, datas, cor, upload, segmented, rating e custom fields.

04

Actions assíncronas

Loading por botão, validação automática, prevenção de double-submit e retorno por Promise.

05

Cross-window best effort

Publicação em window, parent, top, frames e opener quando same-origin permitir. Cross-origin continua respeitando o sandbox do navegador.

06

API imperativa opcional

setValue, setValues, validate, update, close e result sem sacrificar o modelo declarativo.

const menu = RodMenu.open({
  title: "Criar publicação",
  presentation: "bottom-sheet",
  fields: [
    { type: "text", name: "title", label: "Título", required: true },
    { type: "switch", name: "public", label: "Público", value: true }
  ],
  actions: [
    { id: "cancel", label: "Cancelar", role: "cancel" },
    { id: "save", label: "Salvar", role: "submit" }
  ]
});

const result = await menu.result;
