How I like to build

Useful first. Weird second. Fast always.

01

Browser-first

Small tools should stay close to the platform: less ceremony, fewer accidental dependencies and more native browser APIs.

02

Mobile is not a reduced desktop

Gestures, viewport behavior, focus, scrolling, safe areas, thermal performance and thumb ergonomics change the entire problem.

03

Debugging deserves interface design

Internal tools deserve hierarchy, feedback, readable transitions and error states that are impossible to ignore.

04

Performance is part of the interaction

An interface does not feel fast just because it saves a few milliseconds. It needs to react immediately and move only what actually matters.
