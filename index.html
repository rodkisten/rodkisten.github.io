How I like to build

Useful first. Weird second. Fast always.

01

Browser-first

Ferramentas pequenas devem conseguir viver perto da plataforma. Menos ceremony, menos dependência acidental, mais APIs nativas.

02

Mobile is not a reduced desktop

Gestos, viewport, foco, scroll, safe areas, performance térmica e ergonomia de polegar mudam o problema inteiro.

03

Debugging deserves interface design

Ferramentas internas também merecem hierarquia, feedback, transições legíveis e estados de erro impossíveis de ignorar.

04

Performance is part of the interaction

Uma interface não parece rápida apenas porque tem poucos milissegundos. Ela precisa reagir imediatamente e movimentar só o que realmente importa.
