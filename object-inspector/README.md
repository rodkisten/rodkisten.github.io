# Rod Object Inspector — Landing Page

Landing page responsiva, sem dependências e com playground funcional para o
`RodObjectInspector`.

## Arquivos

- `index.html`: estrutura da landing.
- `styles.css`: tema white/dark, responsividade e componentes visuais.
- `landing.js`: tema, playground, busca, snapshots, diff e demos interativas.
- `rod-object-inspector.js`: bundle do inspector usado pelo playground.

## Executar localmente

Sirva a pasta por HTTP para que todos os recursos funcionem de forma consistente:

```bash
python3 -m http.server 8080
```

Depois abra:

```text
http://localhost:8080
```

Também é possível publicar os quatro arquivos diretamente no GitHub Pages.
